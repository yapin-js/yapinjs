Unofficial client mod runtime

Write Yapin’ plugins in plain JavaScript.

yapin.js loads a single .js file into the Yapin’ web client: slash commands, UI patches and themes. No bundler, no dependencies, no package.json.

What the runtime gives you

Everything a plugin touches goes through one object, so everything it touches can be taken back.

  • One file, no build

    A plugin is an ES module with a default export. Drop it in the folder and it loads. Nothing to install, nothing to compile.

  • Hot reload

    Save the file and setup() runs again in place: no page refresh, no losing your place mid-conversation.

  • Clean teardown

    Commands, listeners, styles and patches are tracked per plugin and removed on unload. Disabling a plugin leaves no trace.

  • Scoped storage

    yap.store is namespaced to your plugin and survives reloads, so settings persist without touching anything global.

  • Theme tokens

    Read and override the client’s own CSS variables, like --accent and --bg-side, so a theme stays correct in light and dark.

  • Bots stay bots

    yapin.js runs in your own client, for your own account. Anything that needs to act on its own belongs in Yapin’s bot API.

Quick start

Three steps, in order.

  1. Turn on local plugins

    In Yapin’, open Settings → Advanced and enable developer mode. A plugins folder appears in the panel it opens.

  2. Write the plugin

    Create plugins/hello-yap.js and paste the snippet from the top of this page.

  3. Load it

    Hit reload in the plugins panel, then type /hello in any channel. Edit the file, save, and the change is live.

The yap object

The whole draft surface. Every member is available inside setup().

MemberWhat it does
yap.command(name, fn)Registers a slash command. fn gets a context with reply(), args and channel.
yap.on(event, fn)Subscribes to a client event: message, channel_switch, voice_join, settings_open.
yap.css(text)Injects a stylesheet scoped to the plugin. Returns a handle, so you can remove it early.
yap.patch(selector, fn)Runs fn against matching elements now, and against new ones as they appear.
yap.storeAsync key/value storage, namespaced per plugin: get, set, delete.
yap.toast(text, opts)Shows a notice in the client’s own toast style.
yap.onUnload(fn)Cleanup for anything the runtime cannot track for you.

Bot framework for Yapin’

Build Yapin’ bots in JavaScript.

Commands, events, embeds, buttons and voice in one dependency-free module. Runs on Node 18+, Bun and Deno.

Read the quick start View on GitHub

Pre-release. The API below is a draft and will change.

What the framework handles

The parts of the bot API that are tedious to write twice, and nothing beyond them.

  • Commands and interactions

    Register /slash and !prefix commands in one call. Button clicks route to handlers, with ephemeral replies and live message edits.

  • Events, however they arrive

    Connects over the WebSocket gateway where it is available and falls back to polling /events, resuming cleanly after a dropped connection.

  • Embeds and Components V2

    Builders for embeds and for the newer layout pieces — containers, sections, galleries, separators and files — with the JSON checked before it is sent.

  • Cogs

    Group commands, buttons and listeners into one file, then load, unload or reload it while the bot is running. No restart to ship a fix.

  • Voice

    Watch joins and leaves, move or disconnect members, and stream audio for music bots.

  • Rate limits, handled

    Per-route buckets queue requests and retry on 429, so a busy server does not mean a dropped reply.

Quick start

Three steps, in order.

  1. Create the bot

    In Yapin’, open Settings → Developers, create a bot and copy its token. Invite it to a server you can test in.

  2. Install and write it

    Add the package, then save the snippet from the top of this page as index.js.

  3. Run it

    Start it with YAPIN_TOKEN=... node index.js, then type /ping in your server. Commands register on the first connection.

The Bot surface

The whole draft API. Handlers receive a context with reply(), args, author and channel.

MemberWhat it does
new Bot(token, opts)Creates the client. opts sets the command prefix, intents and gateway preference.
bot.command(name, fn)Registers a command, reachable as /name and !name.
bot.on(event, fn)Subscribes to an event: message, member_join, interaction, voice_join.
bot.button(id, fn)Handles clicks on a button with that custom id, anywhere the bot has posted one.
bot.send(channel, body)Posts a message. body takes a string, or an object with embeds and components.
bot.load(path)Loads a cog. bot.reload(name) and bot.unload(name) work at runtime.
bot.rest(method, route, body)A raw REST call for anything the framework does not wrap yet, with rate limits still applied.
bot.start()Connects and begins handling events. bot.stop() closes cleanly.
